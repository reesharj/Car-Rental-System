# Car Rental System

A console-based **Car Rental System** developed in **C++** as part of a group project for the **Data Structures and Algorithms** course. The system provides a text-based interface that allows customers to register, log in, book or rent vehicles, select pickup or delivery options, choose self-drive or driver services, calculate rental fees, and process payments. Staff can also manage vehicle and driver records using file handling.

## Features

- User registration and login
- Car booking and rental
- Self-drive or driver selection
- Pickup and delivery options
- Rental fee calculation
- Payment processing
- Car and driver management
- File-based data storage

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Data Structures
- File Handling
